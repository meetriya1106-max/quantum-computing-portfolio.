# Comparative Study of 34 Quantum Circuit Primitives

## Overview

This project explores 34 quantum circuit primitives through a structured study of quantum computing, circuit construction, and cross-platform validation.

how they are implemented using IBM Qiskit and NVIDIA CUDA-Q, and how differences in software frameworks can affect circuit interpretation and execution.

As a learning project, it combines theoretical explanations, Python implementations, circuit visualizations, simulation results, and comparative experiments.

## Objectives

- Understand the mathematical foundations of quantum circuit primitives.
- Implement quantum circuits using Qiskit.
- Explore equivalent implementations using NVIDIA CUDA-Q.
- Analyze gate-level circuit composition and measurement outcomes.
- Investigate qubit ordering, state representation, and measurement conventions.
- Compare simulator results across frameworks.

## Primitive Categories

The study is organized into eight logical categories:

1. State Preparation
2. Entanglement Generation
3. Oracle Construction
4. Amplitude Amplification
5. Phase Estimation
6. Basis Transformation
7. Auxiliary and Ancilla Operations
8. Variational and Chemistry-Inspired Ansatz Circuits

## Methodology

Each primitive will be studied through the following steps:

1. Theory and mathematical formulation
2. Quantum circuit design
3. Gate-level implementation
4. Qiskit implementation
5. CUDA-Q implementation, where supported
6. Simulation and measurement
7. Cross-platform result comparison
8. Observations and conclusions

## Tools and Technologies

- Python
- IBM Qiskit
- NVIDIA CUDA-Q
- Google Colab
- Jupyter Notebooks
- GitHub

## Project Structure

Each category will contain documented notebooks and supporting code as the study progresses. Cross-platform comparison results will be maintained separately.
